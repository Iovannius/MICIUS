# INT8 数值契约与自然文本质量

v0.7 沿用 I1 定义的 W8A8 算术。I25 改变权重排列和四个输出行的消费方式。验收分两个问题：整数实现能否产生契约规定的结果，以及激活量化相对 F64 引入的近似是否满足指定文本的筛选条件。

## 一个 32 元素块如何参与输出

权重沿用 GGUF Q8_0 的有符号字节和逐块 scale。绑定时校验 V1 描述符。对输入块中的有限 F32 激活求最大绝对值 M，使用 binary64 的 d = M / 127。零块的 codes 和 d 均为零。其余输入用 binary64 计算 x / d，按最近偶数舍入，再夹到 [−127, 127]。运行要求 MXCSR 使用 round-to-nearest、屏蔽浮点异常，FTZ 和 DAZ 关闭。

每个输出行独立计算，块间按原列顺序执行以下运算。

```text
dot = sum(int32(weight_code[k]) * int32(activation_code[k]))
weighted = double(dot) * double(weight_scale)
sum = sum + weighted * activation_scale
```

权重允许 −128。32 项点积绝对值上界为 520,192，INT32 足以容纳。GEMV 反缩放保持分步乘法和加法，执行有限性及 F32 范围检查后写回。FFN 的 gate、up 消费同一个输入快照。I25 将四行的权重字节与 scale 按块重排，四行同时消费，每行保留上述块序与舍入点。[块量化与独立参考](history/int8/I01.md) · [四行消费实现](../src/AI/i25/PanelGEMV.cpp)

## 从误差位置到因果干预

I2 固定 token 42 和 1，在 F64 和 I1 各自的首步轨迹内冻结 GEMV 输入。644 次矩阵、45,219,840 个块位置通过独立量化、INT64 点积、后处理和实际输出检查。该组激活上的算术分组差异未改变最终 F32 输出。两条轨迹的最终 logits 相对 L2 却分别达到 19.8393% 和 15.2640%。这把研究重点转向了激活近似及其沿残差和 FFN 的传播。R1 修订将 gate/up 输入未改写的观察范围限定在共享准备后的消费阶段。[I2 诊断及复核](history/int8/I02.md)

I3 在同一模型、输入和初始状态上，逐项回切指定 FFN 的 GEMV 精度。把 layer 3 与 31 的完整 FFN 回切到 F64，两条输入的最终相对 L2 分别降至 6.7402% 和 5.2733%。只切末层 gate/up 时分别为 6.3027% 和 8.9508%。同一干预对不同输入的排序可以不同，选取生产策略需要观察真实目标的整分布分数。[I3 干预矩阵](history/int8/I03.md)

## 固定自然文本结果

每篇从 reset 后的上下文开始，连续输入真实 token，预测下一枚真实 token。各位置从完整 logits 用稳定 log-sum-exp 复算 NLL。下表 PPL 为所有有效位置平均 NLL 的指数。

| 主比较 | 目标位置数 | F64 PPL | I1 PPL | I1 − F64 平均 NLL，nats | 预设筛选 |
|---|---:|---:|---:|---:|---|
| I4，WikiText 八篇，每篇 256 个位置 | 2,048 | 14.510838 | 14.508543 | −0.000158 | 通过 |
| I5，另八篇 WikiText 加八部 Gutenberg，每篇 2,048 个位置 | 32,768 | 14.389001 | 14.415024 | +0.001807 | 通过 |

I4 要求整体 PPL 比值 ≤1.02、每篇平均 NLL 增加 ≤0.05 nats。I5 保留这些要求，并检查两种语料、累计前缀及四个位置区间。I5 中 PPL 的相对变化为 +0.180856%，单位置最大 NLL 增加为 0.830614 nats。混合精度在指定子集的平均 NLL 上没有带来保留它的依据。完整对照包含分词器身份、目标错位防护、重置重放和逐篇结果。[I4 方法与结果](history/int8/I04.md) · [I5 扩展评估](history/int8/I05.md)

上述 32,768 个位置是 I1 与 F64 的直接质量比较。其后每个采用的内核按各自固定输入核对全 logits。I25 的正式复跑覆盖两篇各 2,048 个位置，v0.7 发布集成另有三种合成模型的完整轨迹。三类证据的输入范围各有记录。[I25 验收](history/int8/I25.md) · [发布验证](VALIDATION_AND_BENCHMARKING.md)
