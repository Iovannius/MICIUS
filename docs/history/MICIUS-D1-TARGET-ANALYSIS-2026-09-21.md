## 插桩扰动与计时口径

BASE 未编入分类；IDLE 编入但不开启；ON 编入并开启。IDLE 与 ON 使用同一个 PROFILE EXE。

| 模式 | 中位吞吐（tok/s） |
| --- | ---: |
| BASE | 18.9392055 |
| IDLE | 18.9028945 |
| ON | 18.9695680 |

| 配对比较 | 中位耗时变化 |
| --- | ---: |
| BASE → IDLE | +0.199990% |
| IDLE → ON | −0.145704% |
| BASE → ON | −0.000470% |

未触发预设的绝对配对中位耗时变化 >2% 警戒线，支持以本次分类判断优化覆盖范围。这不是零开销证明，微小负值也不代表开启计时加速引擎。该警戒线不是候选晋升门槛。

正式 ROI 不含模型加载、prompt、warmup 及窗口后的 logits copy/checksum/output。GEMV exclusive 扣除了内部 activation 准备，仍包含对应 wrapper、状态检查及分派，并非裸内核计时。准备包含有限值扫描、F64 转换及 scratch 写入；FFN gate/up 共享准备仅记一次。other_forward 包含 attention、norm、逐元素运算、greedy 和其他未分项工作，不能当作某个单独算子的时间。

每个 ON 样本有 20,608 次 GEMV、16,512 次准备、128 次 forward，共 37,248 个 scope，不含 warmup。ROI 后空 scope 探针为约 46.2–47.22 ns/次；乘以 scope 数仅给出约 0.0253–0.0261% ROI 的量级估计，不是实际分类误差，也未从测量中扣除。

## 机器码对应

BASE / PROFILE 的 prevalidated 及 checked 双行完整 block 主循环，分别与已验收 PW2 NONE **逐字节一致**。

| 主循环 | 静态指令 / 字节 | 循环内栈访问 / CALL / FMA / EVEX |
| --- | ---: | --- |
| prevalidated | 98 / 486 | 0 / 0 / 0 / 0 |
| checked | 111 / 581 | 1 个整数边界读取 / 0 / 0 / 0 |

prevalidated 仍有 16 条 `vpmovsxbd`、16 条 `vcvtdq2pd`、32 条 `vmulpd`、16 条 `vaddpd`、8 条 prepared activation `vmovupd`。其编码 SHA-256 为 `11a01ac101cf528cc5d5edec3080c4c35ed4a43baf0a1349b24516d44cf43e3a`。checked 的栈读取不是浮点累加器 spill。

这排除了“D1 改写了这两条主循环”的解释，不证明整个调用链无 CALL/栈访问或整个 forward 无 FMA。静态指令数不是周期数；D1 没有测量 PMU 端口、缓存层级或实测内存带宽。

## 对既定 F64 目标的约束

条件预算：目标代码占比 p、局部速度倍率 s，其余耗时不变时，整体倍率为 `1 / (1 − p + p/s)`。以整体 **1.66×** 代表原始提升区间的一个预算点，不把它另定成唯一门槛或性能预测。

| 候选覆盖范围 | 占比 | 达到整体 1.66× 所需局部倍率 |
| --- | ---: | ---: |
| activation 准备 | 0.1246% | 不可能；理想消除也仅约 +0.1247% 整体收益 |
| QKV + O | 20.7788% | 不可能；理想消除也最多约 **+26.23%** |
| FFN 三项 | 62.5708% | 约 **2.743×** |
| FFN + LM head | 74.9967% | 约 **2.128×** |
| 全部 GEMV | 95.7772% | 约 **1.710×** |

局部倍率指该范围的综合耗时变化。工作集、准备和其他路径变慢必须在真实结果中计入。即使假设 QKV/O 在 decode 中均提高 34% 局部吞吐，整体预算也仅约 +5.57%；A2 单矩阵结果不证明这一假设。PW1/PW2 真实模型负收益及 A1/A2 轮转结果继续有效。

D1 把此前“当前 GEMV 可能占 85–90%”的猜测替换为本批约 95.78% 的测量。它没有证明保持现有 F64 契约的候选能做到约 1.71×，也不支持 INT8 35–50 tok/s 的概率预测。历史 9.39 → 18.9 tok/s 仍缺同条件因果归属，不能称为已经清除巨大实现损失。

本轮没有发现新的运行时缺陷，没有修改数值路径，没有可晋升候选。D1 分类任务结案。
