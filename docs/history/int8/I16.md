环境核验仅覆盖记录中的电源、亲和、挂起时钟和进程快照；没有温度/有效频率证据，不能声称桌面噪声为零。探针耗时未从结果中扣除，总体开销小也不证明每个局部计时误差都小。

#### 比较边界

主比较组为 Score + Softmax + Value；它容纳了两引擎缩放、最大值搜索与概率归一化的归属差异。矩阵组包含 MICIUS 激活准备，llama 的相应工作在 GEMV 内。
MICIUS Score 包含缩放和最大值搜索，llama 将它们放在 Softmax；MICIUS 概率归一化在 Value，llama 放在 Softmax。Softmax + Value 合并只能对齐后一项，原始三行均不能直接称为“相同数学算子的性能差”。本次重新核对了冻结 llama 源码及摘录散列。
两引擎还存在精度、累加次序、掩码、布局和检查差异；Attention 核心以外的图/布局操作仍保留在原分组。完整功能组差额支持研究优先级，不能视为已经证明可回收的时间。llama argmax 包含在 forward 余量中，KV 写入按 layer=-1 汇总，也不能比较跨引擎每次调用或逐层 KV 的速度。
