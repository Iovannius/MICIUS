可用 Amdahl 上界评估优先级：某阶段占总时间比例为 p，即使无限加速它，总加速也不超过 1/(1-p)。这一上界是优先级工具，不是性能承诺。新的无 VNNI I1 与 llama OFF 差距应来自 I9 本次未插桩配对；I8 的历史数值不混入本轮。

#### 优先级与下一单元

建议 I10 首先处理 Attention Value 的 AVX2 寄存器分块路径，随后评估 Score/KV 访问；矩阵消费继续列为另一条主优化线。

Attention Value 当前平均 21.732 秒，占 MICIUS 18.60%，而 llama 对应类别约 6.622 秒。源码显示每个时间位置反复从 output 加载、转成 double、执行 F64 FMA、舍入回 F32 并写回。因此第一项候选应检查 head_dim=64 的寄存器保留和循环安排，而不是直接改变累加精度。

候选应保留逐时间步顺序、F64 FMA 和每步 F32 舍入，提供通用回退；不引入 VNNI，不修改公共 ABI、冻结原内核或稳定默认策略。收益须在真实机器码和未插桩端到端运行中证实。寄存器溢出或重复概率计算可能抵消收益，尚不能承诺速度。

激活准备只有 0.724%：即使理想化地完全消除，Amdahl 上界也仅约 1.0073×。因此不适合作为第一项提速工作。

只优化注意力也不足以保证追平：按本轮成本占比，即使把整个注意力理想化为零成本，上界约 1.779×；这仍低于当前约 1.948× 的差距。矩阵消费最终也需要优化。这些是算术上界，不是可兑现的性能预测。

下一包先完成合成边界、历史输出和同输入正确性检查，再由用户在核心目录 Bash 采样。新候选与 I9 无 VNNI I1 同场配对，以未插桩总时间和各上下文区间为主要验收；持续保留 llama OFF 的同场参照，LLAMA_ON 仍是最终工程标尺。若改变了数值契约，应单独设立精度候选并重做相应质量验收。
