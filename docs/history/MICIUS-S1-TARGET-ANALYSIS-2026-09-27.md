## 3. 机器码与差异机制

统计范围是预验证、prepared activation 的双行完整 32 列 block 主循环。

| 项目 | 原 Q8（仅正确性对照） | E1 | S1 |
| --- | ---: | ---: | ---: |
| 指令数 / 编码字节 | 98 / 486 | 86 / 441 | 88 / 439 |
| vpmovsxbd / vcvtdq2pd | 16 / 16 | 16 / 16 | 16 / 16 |
| vmulpd | 32 | 16 | 16 |
| vaddpd / vfmadd213pd | 16 / 0 | 0 / 16 | 0 / 16 |
| activation 向量载入 | 8 | 8 | 8 |
| 向量栈写 / 读 | 0 / 0 | 3 / 3 | 0 / 0 |
| 向量寄存器间搬运 | 0 | 0 | 6 |
| 循环内 CALL / 硬件 fence / EVEX | 0 / 0 / 0 | 0 / 0 / 0 | 0 / 0 / 0 |

本批 E1 热循环与已验收 jr8afpk1 的 E1 **逐字节一致**（SHA-256 `0c14ed4adb8c4ca2be3468cfd976e53670347e19b545f9f86cfcdd9ba0a1abf0`）；Q8 主循环也与既有 E1/D1 证据一致（`11a01ac101cf528cc5d5edec3080c4c35ed4a43baf0a1349b24516d44cf43e3a`）。S1 循环为 `ebd3b47d03a5bb5a8125b8f18423103966e6be3219d78fc8dd7b494e5e80916c`。本批没有 Q8 正式计时，不能由此给出新的 S1/Q8 实测比。

S1 源码在每四列双行更新后，用空 asm 的 8 个 `+x` 累加器约束和 memory clobber 限制编译器调度。它没有发出 CPU fence；它也没有改变四条累加链的项序、规约、尾部、scale 资格或权重表示。沿用 E1 已有数值合同与适用条件，不放开对通用 F32 scale 的任意融合。

**去 spill 并非免费。** E1 的三次栈读中，两次折叠在 FMA 的内存操作数里，只有一次是独立 reload。S1 删除三条 store 和一条独立 reload，并将两条内存 FMA 改为寄存器 FMA；同时新增六条 `vmovapd` 寄存器搬运，故指令总数净增 2，而非净减 6。逐条数据流可追踪到六次搬运均传递两个 broadcast scale 的值，每行 scale 各三次。见 `mechanism-review.json` 与两份主循环摘录。

这证明了该调度方案在消除栈访问时引入了额外寄存器搬运，并限制了可用调度空间。**现有计时不能量化每条搬运或原 spill 的独立周期成本，也不能断言收益完全被六条搬运抵消。** 它们还伴随指令排序、寄存器分配和依赖关系变化。没有 PMU 数据来分解端口、前端、缓存或频率影响；不需要为了否决 S1 晋升而补测这些机制。

两侧最外层入口均 57 B；Consume 均 404 B，去掉直接 CALL 的相对地址后字节一致。Consume 静态各有两处 CALL，分别属于回退与快速消费分支，不是每次连续调用两次。重复计时循环保留每次间接调用及状态检查；工作未被消除。主循环无 CALL/栈访问不能扩写为整个调用链无 CALL/栈访问。

## 5. 工程决策与下一项边界

1. **S1 不晋升，E1 保留为当前候选基线。** 本批不要求用户重跑，也不选择性保留 QKV 正收益。S1 源码和失败的性能假设作为独立实验保留，无需回滚正式引擎，因为本次没有修改正式运行时。
2. **确认了具体边界：无 spill 不是性能充分条件。** 本次否定的是“这组空 asm 调度边界能普遍带来增益”，没有证明所有去 spill 方法都无效，也没有证明 F64 优化空间已经耗尽。
3. **下一候选先针对 FMA 结果承接及 scale 寄存器驻留。** 目标是在固定数值合同下减少 scale 迁移，同时维持独立累加链的调度空间。先观察实际目标等价 Clang 代码是否比 S1 减少搬运、是否重新引入 spill，再决定一次固定批次的测量；不先扩大编译选项搜索。本报告没有声称这种候选已经存在或一定提速。
4. 近原始驻留样本收益区间仍是当前 F64 工程目标，S1 未将其兑现。既有 E1 的约 15–19% 合成消费收益继续有效，但不能与本批 S1/E1 百分比跨批相乘为“累计实测收益”。真实模型的资格覆盖、集成 parity、准备生命周期和 decode 净增益仍待相应候选集成后验证。

本轮状态：目标构建/数值/运行器/机器码检查已完成；性能结论为不晋升；真实 decode 未做；INT8/VNNI 未进入。
