# MICIUS PW1 ACCESS A1 目标分析 · 2026-09-19

**本批有效，无需重跑。O 的预展开收益在单矩阵重复与32矩阵轮转之间发生正负反转；QKV 在本批单矩阵条件下已经为负，轮转进一步恶化。** 这为PW1的工作集解释补上了受控访问实验的证据，但不构成完整decode或内存子系统成本分解。

本轮仅分析现有归档并设立后续边界，没有新构建、性能采样、运行时修改或新表示候选。

## 3. 因果结论及限制

对O，保持程序、编译配置、预先分配、activation及数值契约，改变访问集合与次序，就观察到F64相对Q8从+16.42%转为−52.31%。F64对轮转的惩罚远大于Q8。这个结果支持：**热循环省下转换，并不足以抵消较大表示在轮转工作集中的访问成本。** 它与PW1真实decode的负收益方向一致。

这里的“访问成本”包含权重/scale/输出访问范围、复用距离和相关地址行为。single只消费矩阵0，rotate消费32份不同合成矩阵；不是对所有物理地址、数据和缓存状态严格相同的比较。QKV两种权重在32份矩阵中均记录为模64对齐0，O的F64也均为0，不能把负收益解释成已证实的F64未对齐加载缺陷。

| 形状、32份矩阵 | 活跃Q8 raw+descriptor范围 | 活跃F64 raw+descriptor范围 |
|---|---:|---:|
| QKV | 70.3125 MiB | 398.4375 MiB |
| O | 42.1875 MiB | 239.0625 MiB |

范围包括每block的16 B descriptor，未含activation/输出及其他对象；是逻辑访问范围，不是实测DRAM流量。Q8和F64都保留在进程内，但单次消费只读对应权重表示。容量可容纳不等于合适的活跃工作集。

只作为数量级校对：各轮轮转F64−Q8的GEMV时间差乘32，配对中位约QKV 7.514 ms、O 4.372 ms。PW1实际decode的对应配对增量为6.641/4.057 ms。二者接近支持解释的合理性，但跨实验输入、顺序与计时范围不同，不能将其视为逐算子实测或计算“解释了百分之多少”。

尚不能定因的内容：

1. 没有PMU和DRAM流量测量，不能区分各级cache、TLB、带宽、预取与频率状态的具体贡献，也不能确定一个通用缓存容量阈值。
2. A1不包含完整层间FFN/LM head访问，−53%/−52%不能直接写成decode吞吐损失；真实decode结论继续使用PW1的−11.36%/−7.16%。
3. QKV单矩阵未复现旧RB1的+16.90%。旧B保留在线activation转换且分母是旧A，本批为prepared activation及PW1入口，分配、输入和跨批机器状态也不同。不能只凭这些差异列举便声称已经解释完；若未来依赖这一差距选型，最小观察应是在同批同输入/分配中并排消费旧B与当前prepared-weight入口。本轮不增加该实验。
4. 历史r1约9.4 tok/s与PW1 NONE约19.48的跨批绝对差异没有新增证据，本批不用于解释它。

## 4. 后续工作边界

- 保留PW1默认NONE，QKV/O全32层raw F64物化均不晋升。这项决策有真实decode与访问对照共同支持；不再通过重复同一批采样、微调白名单或扩大F64分配预算来追求正收益。
- B/resident的收益有效，但不能据此承诺全模型收益。矩阵类型和单矩阵收益均不足以作为启用条件；需要明确完整访问序列、复用距离、活跃表示容量和实际复用次数。
- 后续预转换候选必须带来不同且可解释的成本结构，例如更小的精确表示，或真实存在的多次消费。先给出字节预算与准备摊销，再决定是否实现。每token展开一次、消费一次仍无免费准备依据。
- raw int8→F32再进入既定F64算术可作为尚未验证的候选方向：整数值精确，但仍有4倍raw存储和F32→F64转换。本批没有验证其收益，也不把它定为必做或默认可采纳方案。
- 冻结参考、算术顺序、scale语义、准备/消费生命周期和原Q8表示保持。诊断胜出后仍需独立候选及必要真实模型比较才可晋升。
- 本轮未发现需要修复的新数值、构建或计时缺陷。F64阶段不因此自动结束，W8A8/VNNI仍不实施。当前交付是分析与边界记录，不是新运行脚本或安装包。

当前已经回答了本次实验的主要问题：访问方式改变能让至少O的预展开净收益反转；QKV轮转也明显放大损失。因此无需再重复A1或PW1批次来确认这个方向。后续只针对一个有明确决策用途的未知推进。
