# M4-D1 · Llama 首词独立对照

M4-P1 中 Llama-3.2-1B-Instruct-Q4_K_M 首轮回复 `No`，没有遵循提示“只回复 blue”。D1 用另一套实现检验该首词行为，不通过改变提示或采样参数来掩盖原结果。

## 固定输入与方法

运行号 `d1-20261121-233647-a3435e15`；2026-11-21 用户执行，随后独立复核。使用同一 GGUF、原首轮提示 `Reply with only the word blue.`、context 512、单线程 CPU、贪心且不施加重复惩罚。原始模板中的固定日期保留为 `26 Jul 2024`。

独立 llama.cpp 按该 GGUF 自带模板渲染并分词，42 个提示 token 与 M4-P1 完全一致。两套引擎逐 token 消费这些固定输入，每个提示前缀保存完整 F32 logits；预测不反馈为后续输入，最后一行决定首个生成 token。llama.cpp 使用 batch 1、F32 KV、关闭 FlashAttention。MICIUS 使用原 M4-P1 INT8 SDK，其混合权重实际消费路径为 `gguf_block_dequant_ordered_f64`。

参考使用此前冻结的本地 llama.cpp 0.6.0 源码归档与库，不声称其为当前上游版本；归档没有提供 Git commit。具体模型身份、参考归档 SHA-256、42 个 token 与模板输入见 [固定协议](evidence/m4-d1-protocol.json)。上游运行库不打入 MICIUS 源码包或 SDK。

## 结果与边界

| 项目 | MICIUS | llama.cpp |
|---|---:|---:|
| 最后提示位置的首选 token | 2822 (`No`) | 2822 (`No`) |
| 首选与次选 logit 差 | 0.800478 | 0.836710 |

首词诊断结论为 **FIRST_TOKEN_MATCH**。同一固定模型与提示下，`No` 也被参考实现选中，因此不能将这个回答单独用作 MICIUS 特有计算错误的证据，也不能由此唯一归因于模型太小。

完整 logits 不相同。最后一行 RMSE 为 **0.156452**，最大绝对差 **0.791764**，余弦相似度 **0.998153**。42 个提示前缀中 41 个 argmax 一致；零基位置 7（消费第 8 个提示 token 后）的 argmax 分别为 4206 / 8113。这是固定前缀的候选差异，不是实际完整回复已经发生分叉。误差来源尚未归因，不将其写成已证实的正常舍入误差。

本次没有预设完整数值等价阈值，也没有比较完整回复、长上下文、自然文本质量或吞吐。首词一致不能把以上项目改判通过。M4 的独立合成数值对照、M4-P1 的实机功能重放、D1 的首词诊断属于不同层次的证据。
