## 解释边界与下一步

CF6 的主要比较是 **实验 CF5 对实验 CF3**；CF7 比较的是 **当前 prepared-Q8 运行时对接入 CF5 的运行时**。两者比较对象不同，前者的微基准收益不能推出后者应有端到端收益。现有结果不互相矛盾，也不证明 F64 已达到性能上限。

对本模型完整块，BASE 的 Q8 与 16 B/block descriptor 存储约为 1.5 B/weight，CF5 bank 约为 3.03125 B/weight；原 Q8 与 descriptors 仍保留。这说明相对 BASE 存在表示容量与消费算术的交换，但存储规模不等于实际 DRAM 流量，本批没有单独确定其因果贡献。

末两轮 CF5 下降更明显；未记录足以隔离频率、功耗、温度或调度影响的数据。不能把 −0.55% 当成稳定固有退化幅度，也不应删去末两轮后重算。可靠决策是：**本轮没有收益证据，且资源成本明确增加。**

保留 CF7 为可复现的候选与负结果，默认继续关闭。后续优先利用已有目标反汇编与数据流，核对运行时消费形态和微基准之间的差异；只有出现可区分的具体假设，才补最小实验。本批无需重跑，不新增性能变体，不进入 INT8/VNNI，也不再设 tok/s 预测值。
