# 开发历史

v0.6 收束了 Q8_32 权重与 F64 参考累加。v0.7 在同一 V1 接口上引入动态 W8A8，把质量、速度与内存作为独立验收项。[v0.6 开发历史](history/v0.6/DEVELOPMENT_HISTORY.md)

| 阶段 | 改变后续决策的证据 |
|---|---|
| I1–I5 | 对独立量化、整数点积与局部 F64 干预的核对解释了部分 logits 偏差。自然文本 NLL 支持保留 W8A8，混合精度未改善固定子集均值 |
| I6–I9 | 连续配对补证建立长程对照。llama.cpp 关闭 VNNI 后仍明显更快，工程研究转向已验证的无 VNNI 路径 |
| I10–I17 | 分别重构 Value、Score 和 GEMV。每次剖分对应特定基线，优先级同时考虑自身绝对成本与同场对手差额 |
| I18–I22 | I18、I20 停在局部筛选。I19 的三头共享 Key 通过验收。I21 校准同场位置，I22 分阶段解释内存并释放加载器描述符 |
| I23–I25 | 四行重排先通过合成完整工作集筛选，再在真实 I22 中测量成本预算。I25 接入完整模型，P1 修复验证器，独立复跑提升 18.46% |
| v0.7 | 2026-11-01 将 I25-P1 纳入正式构建与普通推理入口，另设 F64 参考配置。源码和研究档案沿用 v0.6 的文档层次 |
| v0.7.1 | M1 建立可独立链接的 GGUF 架构模块，并接入 Qwen2。M2 将已验证的词表、模板、UTF-8 文字交互和会话日志接入普通 CLI。两款模型在 INT8、F64 下通过固定多轮问答与重置检查。[验收范围](RELEASE_0_7_1.md) |

M3 在 v0.7.1 上开发逐会话配置、确定种子采样、有效 KV 存盘与跨进程恢复，不再继续 INT8 性能搜索。原数值内核保持不变。2026-11-11 两款模型、两种后端和两种采样模式的 8 项实机用例通过；发布为 v0.7.2，并增加源码根目录的一步 CLI 构建入口。[v0.7.2 发布记录](RELEASE_0_7_2.md)[M3 设计与验收](M3-PERSISTENCE-AND-SAMPLING.md)

各阶段的候选、判据及结果见 [INT8 实验台账](INT8_EXPERIMENT_LEDGER.md)。

M4 在 v0.7.2 上进行 bug 修复和稠密模型兼容性扩展：新增 Qwen3、Llama 3.x RoPE 因子与逐块混合权重解码。保留原 Q8 路径，停止把格式接入描述为 INT8 性能优化。新格式的独立合成数值对照与实际模型验收分别记录；2026-11-21 指定的两款 Q4_K_M 模型完成前向与存盘续聊功能验收；D1 进一步复现了 Llama 首词 `No`，但未证明全部数值等价。2026-11-22 整理为 v0.7.3 发布包。[发布记录](RELEASE_0_7_3.md)[M4 设计与边界](M4-DENSE-GGUF-AND-WEIGHTS.md)
