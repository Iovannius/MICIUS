# 验证与测量口径

M3 的合成检查包括原有 INT8/F64 契约和三项新增测试：采样规则、持久会话状态、验收流程。两套完整配置分别为 30 和 23 项 CTest。外部 C 程序检查安装前缀移动后的模块链接、旧 v0.7 C 对象重链接和跨后端快照拒绝。

新增流程模拟使用微型合成模型执行验收脚本的完整八组流程，并注入中断、缺少 turn 记录、程序修改及证据变化；不得把它记为目标模型通过。[M3 固定实机协议](../validation/m3/protocol.json) 已由用户终端于 2026-11-11 执行通过，8 项用例/32 次调用及两种归档均已独立复核。其重点是回复、有效 KV、logits、历史、配置与 RNG 的跨进程一致性，REVIEW 和 FULL 包保留证据。M3 不进行性能采样或更新旧吞吐结论。[发布说明与实机证据](RELEASE_0_7_2.md) 记录具体覆盖范围。

v0.7.1 的已有实机证据取自 M1、M2，两款模型的旧功能范围见 [发布说明与实机结果](RELEASE_0_7_1.md)。

## v0.7 研究与发布验收（历史）

| 验证层 | 输入与判断 |
|---|---|
| 原生契约 | INT8 配置覆盖块量化、INT64 点积对照、尾行、有序 Attention、所有权和 V1 错误路径。F64 配置运行参考数值与 V1 契约 |
| 发布集成 | 两层确定性 GGUF，分别为 64 维三查询头共享一个 KV 头、32 维非绑定输出权重、127 词表回退。每后端三组，每组 160 步比较所有 logits 和预测 |
| 真实模型验收 | I25-P1 与 I22 在固定 s00/s08 各 2,048 步，四条完整输出与 24 条无插桩端到端计时。有效运行号 `i25-p1-20261031-102126-e089f2f3` |
| 自然文本质量 | I4/I5 的 teacher forcing。逐篇重置，从保存的全 logits 用稳定 log-sum-exp 计算真实下一 token 的 NLL |

发布程序通过普通 CLI 的固定 token 全输出入口与封存程序逐字节比较。INT8 对照为已接受的 I25，F64 对照为从 v0.6 原件构建的 BASE。另检查普通多 token prompt、短程 greedy decode、错误 token、交互 Shell 和 V1 重绑定。Windows Clang64 的固定参考散列随 CTest 提供。[发布记录](evidence/v0.7-verification.json) · [合成轨迹身份](../tests/reference/cli-traces.json)

## 正式性能

实验脚本在用户终端运行。固定输入 token、运行顺序、CPU、预热／重置、供电及样本间隔。每篇每轮取旧／新耗时，篇内取中位，跨篇取几何平均。主计时排除加载、绑定、面板准备、文件写入和全 logits 观察。阶段私有提交量与工作集从独立观察进程读取，生命周期峰值读取正式子进程退出后的 Windows Job 记录。

I25 预设总体速度比 ≥1.05，每篇 ≥0.98，每篇各区间 ≥0.97。两个后端、两篇文本的总体及四段 max/min 各 ≤1.10。每篇生命周期峰值增加 ≤416 MiB，加载后及 2,048 步后均至少减少 128 MiB 私有提交。首轮 P1 波动比 1.1605 超限，保留为测量不确定。独立复跑的最大值为 1.0334。[两轮 I25 记录](history/int8/I25.md)

I1 的早期 greedy 测量让各后端消费自己的输出。I6 起主比较使用相同的固定输入。I7 的短程、长程和 Qwen 记录分别解读。插桩剖分首先检查输出与探针开销。跨轮速度比不能连乘为 I25 对 F64 或 llama.cpp 的正式同场成绩。[性能与内存](INT8_PERFORMANCE_AND_MEMORY.md)

此次发布复用封存的目标模型观测，新增源码、构建和合成模型功能验证。模型、语料、逐位置原始 logits、二进制和机器日志由各自实验包保留。[研究台账](INT8_EXPERIMENT_LEDGER.md)
