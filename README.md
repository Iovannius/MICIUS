# MICIUS: Multicore Inference Concurrency for Integrated UMA Systems

[![Platform](https://img.shields.io/badge/Platform-x86_64%20%7C%20AVX2%20%7C%20AVX--512-lightgrey)]()
[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

**MICIUS** is a bare-metal, pure-asynchronous speculative decoding middleware for AI workloads, designed to completely shatter the memory bandwidth wall on **Unified Memory Architecture (UMA)** systems (e.g., Intel Iris Xe, AMD 780M).
